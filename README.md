# 清醒点 · 大学生防骗指南

一个不依赖任何框架、可离线打开的中文反诈科普网站。用更接近大学生语境的语气，拆穿校园高频骗局，并给出真出事时能执行的止损步骤。

## 打开方式

直接双击 `index.html`，或双击 `打开网站.bat`。

无需安装依赖、无需构建。页面本身不依赖网络；点击“来源与时间”中的外部链接时才需要联网。

## 主要功能

- **13 类骗局图鉴**：刷单、校园贷、冒充公检法、客服退款、门票交易、AI 换脸等，可分类筛选、关键词搜索，点开查看完整套路、红线与正确做法。每张卡片均标注公开来源与发布时间，详情弹窗内可跳转原文。
- **可疑消息体检**：粘贴聊天记录或招聘话术，在浏览器本地匹配高风险信号，给出风险等级、命中词与下一步建议。内容不上传。
- **6 道反诈自测**：真实校园场景单选题，答完立即看解析，最后生成清醒值评分。
- **紧急止损流程**：顶部和首屏都有「已转账？先止损」入口；流程固定为：先打 96110 或银行客服止付，再打 110 报警，最后保留聊天与转账记录，别删记录、别拉黑对方。勾选进度自动保存在本机；可一键复制报警要素。
- **其他**：转盘动画、滚动揭示、移动端导航、弹窗焦点管理、打印 / 存为 PDF、复制分享文案。

## 隐私与数据

- 全站没有手机号、学号、姓名等个人信息收集字段，不接入第三方统计、广告、字体或 CDN。
- 可疑消息体检、反诈自测全部在浏览器本地 JavaScript 中计算，不上传、不保存。
- 唯一写入本机的是止损流程的勾选状态（`localStorage`）；点击“重置流程”即可清除。
- 页面不使用 Cookie。外链仅为骗局来源引用，点击后才会离开本站。

## 可访问性与离线

- 纯静态目录：系统字体、本地 CSS/JS/SVG，无 CDN、无外部字体、无外部图片；断网也能打开和浏览。
- 支持 `prefers-reduced-motion`：CSS 动效关闭，JavaScript 平滑滚动自动降级为即时滚动。
- 键盘可操作：跳过导航链接、可见焦点样式、弹窗 Esc 关闭与焦点圈定、移动导航打开后聚焦首个链接。
- 站内没有内容图片；本地 SVG 图标作为装饰隐藏；首屏诈骗聊天示意图使用 `role="img"` 和描述性 `aria-label`。

## 想改内容？

- **骗局图鉴**：编辑 `app.js` 顶部的 `scams` 数组；字段包括标题、分类、话术、套路拆解、危险信号、正确做法。
- **自测题**：编辑 `app.js` 中的 `quizData` 数组，`correct: true` 的选项为正确答案。
- **消息体检规则**：编辑 `app.js` 中的 `scanRules`，每个规则由关键词、权重和分类组成。
- **配色与字体**：编辑 `styles.css` 顶部的 `:root` 变量。

## 说明

- 这是一个公益科普型静态站点：不收集手机号 / 学号，不接入第三方统计，不使用 Cookie。
- “消息体检”和反诈自测都在浏览器本地计算；止损进度只写入本机 `localStorage`。
- “消息体检”基于本地关键词规则，只作辅助提醒，不能替代警方判断。
- 遇到真实诈骗，请尽快拨打 **96110** 或 **110**；被骗不是你的错，沉默才会让损失变大。
